# React Fundamentals – Practical Examples

A beginner-friendly project exploring the fundamentals of React.js through simple HTML examples. This repository covers React components, the Real DOM, reusable components, and the Virtual DOM concept.

## 📌 Project Overview

React is a JavaScript library used to build interactive user interfaces. This project contains practical examples designed to help beginners understand how React renders UI elements and organizes reusable components.

## 📂 Project Structure

```text
React-Fundamentals/
│
├── component -In react.html
├── Real-Dom.html
├── Reusable-Componant.html
├── Virtual-Dom-Concept.html
└── README.md
```

## ✨ Topics Covered

| File | Topic | Description |
|---|---|---|
| `component -In react.html` | React Components | Creates and renders a simple product component using React. |
| `Real-Dom.html` | React and DOM | Introduces React and ReactDOM and renders a greeting in the browser. |
| `Reusable-Componant.html` | Reusable Components | Demonstrates product components with different names and prices using props. |
| `Virtual-Dom-Concept.html` | Virtual DOM Concept | Explores repeated rendering and changing displayed values. |

## 🛠️ Technologies Used

## 🚀 Getting Started

No build tools are required for these CDN-based examples.

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/React-Fundamentals.git
   ```

2. Open the project folder:

   ```bash
   cd React-Fundamentals
   ```

3. Open any `.html` file in a modern web browser.

4. Explore the code and observe how React elements and components are rendered.

**Note:** These examples load React, ReactDOM, and Babel through CDN links, so an internet connection is required.

## 🎯 Learning Objectives

- Understand the basics of React components.
- Learn how React renders elements into a web page.
- Explore reusable UI components and props.
- Understand the basic idea of the Virtual DOM.
- Practice integrating React into simple HTML pages.
